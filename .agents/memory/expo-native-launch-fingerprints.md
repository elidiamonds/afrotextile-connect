---
name: Expo native launch fingerprints
description: Native iOS launch PNG bytes can change when Expo prebuild tooling changes even when approved source artwork is unchanged.
---

Keep source launch-asset hashes separate from hashes of files generated by Expo prebuild. When the source artwork still matches its approved hash but the native catalog output changes, compare the deterministic generated hashes and update only the native-output fingerprints.

**Why:** Publishing failed because the native iOS check retained fingerprints from an older Expo-generated PNG encoding while the source icon and splash remained unchanged.

**How to apply:** Re-run the native prebuild check after Expo or image-pipeline changes; treat a source hash mismatch as an artwork problem, but treat a native-only mismatch as a generated-output fingerprint that needs review.
